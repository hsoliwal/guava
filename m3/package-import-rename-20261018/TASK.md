# Guava package and import rename

The authorized delta recursively renames `com.google.common` to
`com.m3.collections.guava` and `com.google.thirdparty` to
`com.m3.collections.guava.thirdparty`. Class and method names stay unchanged.
The immutable original source authority is Git commit
`dfd9dca629d44faf71846b1f85acd38556f4854d`.

The complete frozen inventory contains 3,274 Java inputs, partitioned without
omissions into 1,595 Android and 1,679 JRE attribution domains. The shared real
OpenRewrite ChangePackage owner produced all Java source postimages. Both domains
completed lossless parsing and fixedpoint checks before one full-inventory union
preflight promoted their outputs. The actual loaded Java provider JAR identities
and SHA-256 values are bound in the two SDK execution receipts.

The same canonical implementation separately admits exact Java literal tokens,
XML scalar/text metadata, JDK module declaration/directive names, and exact
resource paths. Three module descriptors use the JDK compiler ModuleTree API;
that execution is explicitly distinct from OpenRewrite and from module consumer
compilation. Historical source/recipe/oracle records are retained as historical
records, rather than used as current execution claims.

All 1,865 production/support Java sources preserve their complete source bytes
after admitted namespace spelling normalization. Of the other Java inputs, 69
files additionally lose redundant import declarations through ChangePackage;
the remaining deliberately changed standalone proof receives an explicit
same-class refusal. The complete original oracle is recovered from its immutable
Git object for independent differential execution. No product algorithm changes
are admitted.
