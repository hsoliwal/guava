## Accepted physical scope and lifetime

Replace private AvlNode left/right and sorted predecessor/successor object links with primitive slot columns in one range-shared SlotStore. Store element payloads in Object[], element counts and distinct aggregates in int[], occurrence aggregates and generation stamps in long[], and heights/state in byte[]. Slot zero replaces the constant header node. No alternate public collection or public identity change is allowed.

This is an explicitly partial topology conversion, not node-free or pure primitive retained storage. The first entry wrapper for a live slot generation allocates one shared ExportedCount object containing only an int. All later wrappers for that generation share it. An exceptional cursor-chain capture can allocate that same state for each captured generation before entry export. The arena retains this state only while the original node generation remains reachable. Retirement transfers its final count into that state and clears the arena reference; only existing wrappers/cursors then keep it alive. An empty owner must retain neither former element payloads nor exported compatibility states, even after arbitrarily many rejected reentrant mutations. Ordinary additions and forEachEntry without entry export or nested exceptional cursor capture must not allocate compatibility objects. Full entry traversal can leave one compatibility object per live distinct element, and that shape must be reported.

Detached traversal can require an iterator-owned array chain of element references, shared count states, generation stamps, direction links and a primitive lookup index. A cursor created inside an already active arena operation is also registered in a temporary descriptor array even if no retirement is pending yet. Its current position is kept current. Before the outermost operation releases any generations, refresh those descriptors from the final still-leased links, including generations inserted after cursor creation. Clear every registration and the arena's descriptor array in the outer finally on both success and failure. The arena must retain no cursor registry between operations. The explicit additional storage is O(C + sum of captured chain lengths), where C includes cursors created and discarded inside that active operation. After exit, only escaped iterators retain their captured chains. Nested internal iteration, including bounded clear, can allocate a descriptor as well; ordinary top-level iterator construction does not.

The earlier primitive historical-generation design is rejected: it accumulated unbounded count records on an empty owner after callers dropped entries. Keep its counterexample and source snapshot as failed evidence. Do not receive it.

## Mandatory behavior

Preserve comparator traversal and direction, original exception and overflow timing, AVL rotations, sorted iteration, live range sharing, saturated sizes and exact aggregates for ordinary operations. Exported entries keep the original element object. A live generation reads its current count; a detached generation with a positive count after rejected reentry keeps that positive count; zero detached count falls back to the original owning view's count of a comparator-equivalent element. Slot reuse must never redirect an entry to an unrelated generation.

Keep the original root-identity conflict check, including successful same-root reattachment and partial writes after a rejected different-root update. Do not blanket release every queued slot or newly acquired slot. On structural comparator/visitor reentry or root conflict, trace the authoritative root and header through all four original links; preserve every reachable original generation, free only true orphans. If reentry leaves root and linked-order topology inconsistent, subsequent structural operations retain graph reconciliation until that exceptional shape is removed. Ordinary well-formed operations do not pay the full scan.

A cursor detached within its own callback captures its remaining direction chain before release and keeps that chain across in-call slot reuse. A detached prefix must reconnect to current live-generation counts and links, so later visitor writes and insertions remain visible. A cursor created by a nested callback must observe later outer-frame detached count writes and newly inserted then retired successor generations. Preserve range endpoint NPE timing and comparator trace in both directions, including a later clear that nulls a previously captured link. Ordinary iterator behavior after unrelated external structural mutation remains the original unspecified boundary. Retire must always zero the count even if queue membership was already recorded; queue insertion alone is idempotent.

Publish all grown columns only after successful allocation, reload array fields after comparator-bearing recursion, and defer retired storage release until active operation frames finish their post-callback reads. Keep custom comparator/element/count serialization, deserialization replacement, serialVersionUID 1, and nonserializable live entry wrappers.
